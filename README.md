# ML Calibration and Hyperparameter Search

## Overview

This project demonstrates practical machine learning techniques for regression evaluation, probability calibration, and hyperparameter optimization.

The project uses a placement prediction dataset and explores both regression and classification tasks.

## Topics Covered

### 1. Regression Evaluation
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Percentage Error (MAPE)
- R² Score
- Effect of outliers on MAE and RMSE

### 2. Probability Calibration
- Sigmoid / Platt calibration
- Isotonic calibration
- Reliability diagrams
- Brier score

### 3. Hyperparameter Search
- Grid Search
- Random Search
- Bayesian Optimization preview
- Gaussian Process
- Expected Improvement
